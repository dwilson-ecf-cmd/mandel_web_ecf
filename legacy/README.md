# Сохранённые унаследованные материалы

Каталог отмечает прежнюю границу изоляции; после завершения разрешённых снятий в нём не остаётся исполняемого исходного кода. История файлов сохраняется Git и авторитетными записями о снятии.

Авторитетные переносимые контракты находятся в `shared/`, их реализация и композиция — в `runtime/`, а намеренная совместимая граница рендерера — в `server/renderer/`.

Соответствие старых и новых путей, суммы и ограничения приведены в `../docs/architecture/legacy_path_map.md`. Условия снятия с эксплуатации задаёт `../docs/legacy_retirement_criteria.md`. Python- и C++-серверы, а также иностранные исполняемые файлы имеют статус `RETIRED` и сохраняются только историей Git; автономные исходные рендереры также имеют статус `RETIRED`. UI и носители вне каталога имеют статус `PRESERVED_REFERENCE`. Совместимый рендерер вне этого каталога имеет статус `COMPATIBILITY`. Перемещение сохраняет материал и не предоставляет разрешения удалить, переписать, пересобрать или активировать его.
