# Двухклиентская архитектура

Fractal Studio Desktop и Fractal Studio Mobile являются равноправными окнами в общую Workspace в пределах выданных возможностей. Оба строят состояние только из снимка и предлагают область фрактала, настройки рендера, выбор модулей, ход поколений, предварительный просмотр, анализ, историю артефактов и открытий, присутствие и аренду.

Desktop дополнительно содержит концептуальную локальную административную оболочку: одобрение и отзыв устройств, удалённый доступ и приглашения, квоты, работники, аудит, остановка всех заданий, отключение шлюза и смена служебных учётных данных. Эти средства пока не реализуются.

Mobile может кэшировать лёгкие снимки и просмотры, но не вычисляет фрактал, не загружает нативные формулы, не планирует работников, не кодирует авторитетные артефакты, не читает произвольные файлы, не запускает процессы, не устанавливает модули и не администрирует ОС. Подключение новой сессии не создаёт нового логического участника.
