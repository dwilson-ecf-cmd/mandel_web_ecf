# Двуязычный технический глоссарий

Английская колонка сохраняет точное машинное или концептуальное обозначение.
Русская колонка задаёт термин для будущего технического текста. Идентификаторы
в обратных кавычках всегда сохраняются на английском языке.

| English machine/concept term | Approved Russian technical term | Notes |
|---|---|---|
| module | модуль | Машинные `module_id` не переводятся. |
| socket | сокет (точка подключения) | Не путать с сетевым сокетом; в этом проекте это подключаемый контракт модуля. |
| contract | контракт | Версии контракта и идентификаторы сохраняются. |
| interface | интерфейс | Включает публичные структуры, функции и таблицы операций. |
| ABI | ABI | При первом упоминании допустимо «двоичный интерфейс приложений (ABI)». |
| API | API | При первом упоминании допустимо «программный интерфейс (API)». |
| runtime | среда выполнения | Для конкретного слоя допустимо «исполняемая среда». |
| registry | реестр | `fractal_module_registry` остаётся без перевода. |
| descriptor | дескриптор | Описывает модуль и его возможности. |
| capability | возможность | Битовые флаги возможностей не переводятся. |
| formula | формула | Математические формулы и их идентификаторы неизменны. |
| formula state | состояние формулы | Ограниченное непрозрачное хранилище, принадлежащее вызывающей стороне. |
| recurrence | рекуррентность | Один математический переход состояния формулы. |
| termination rule | правило завершения | Определяет, завершена ли точка до исчерпания бюджета. |
| parameter identity | идентичность параметров | Детерминированный идентификатор канонических параметров формулы. |
| execution identity | идентичность выполнения | Детерминированный идентификатор исполняемого контракта модуля. |
| numeric backend | числовая реализация | Не означает платформенный серверный бэкенд. |
| computation module | вычислительный модуль | Модуль, формирующий поле по назначению. |
| scheduler | планировщик | Отвечает за декомпозицию и жизненный цикл работников. |
| sealed work unit | запечатанная единица работы | Seal передаётся как «печать» только в поясняющем тексте. |
| assignment | назначение | Детерминированный диапазон работы, переданный вычислительному модулю. |
| immutable field | неизменяемое поле | Не подразумевает владение хранилищем. |
| analyzer | анализатор | Наблюдает поле и создаёт типизированные записи. |
| analyzer chain | цепочка анализаторов | Порядок объявления является порядком выполнения. |
| rasterizer | растеризатор | Преобразует поле в пиксели. |
| encoder | кодировщик | Владеет форматом байтов, но не местом назначения. |
| artifact | артефакт | Опубликованный результат кодирования. |
| artifact sink | приёмник артефактов | Управляет местом назначения и транзакционным жизненным циклом. |
| manifest | манифест | JSON-ключи и значения идентичности не переводятся. |
| checksum | контрольная сумма | Конкретные значения и названия алгоритмов неизменны. |
| deterministic identity | детерминированный идентификатор | Идентификатор воспроизводимости, не обязательно криптографический хеш. |
| cancellation | отмена | Кооперативная остановка на определённой границе. |
| failure | отказ | Ошибка выполнения или проверки; не обязательно сбой процесса. |
| ownership | владение | Описывает ответственность за срок жизни и освобождение ресурса. |
| caller-owned | принадлежащий вызывающей стороне | Вызываемая функция не освобождает такое хранилище. |
| borrowed view | заимствованное представление | Не владеет данными и ограничено сроком вызова. |
| compatibility | совместимость | Включает совместимость ABI, возможностей и данных. |
| replay | повторное воспроизведение | Проверяемое повторение с теми же контрактами и идентичностями. |
| transactional publication | транзакционная публикация | Результат видим только после успешного `commit`; иначе выполняется `abort`. |
| reference implementation | эталонная реализация | Поведение, используемое как оракул совместимости. |
| legacy implementation | унаследованная реализация | Сохранённая прежняя реализация; не означает автоматическое удаление. |
| unavailable backend | недоступная реализация | Зарегистрирована явно и возвращает `NOT_IMPLEMENTED`. |
| refinement contract | контракт уточнения | Машинные идентификаторы CDC остаются на английском. |
| proof obligation | обязательство доказательства | Математическое условие, которое требуется снять. |
| bounded proof search | ограниченный поиск доказательства | Поиск с явной конечной границей ресурсов или глубины. |
| field | поле | Типизированный массив результатов вычисления. |
| record | запись | Типизированный результат анализатора, не произвольный набор свойств. |
| worker | работник | Поток выполнения, которому назначена единица работы. |
| overflow | переполнение | Проверяемое арифметическое переполнение; насыщение не предполагается. |
| borrowed | заимствованный | Не передаёт владение. |
| lifecycle | жизненный цикл | Упорядоченная последовательность допустимых состояний. |
| canonical serialization | каноническая сериализация | Стабильный порядок и представление значений. |
| provenance | происхождение | История и авторский контекст сохранённого материала. |
