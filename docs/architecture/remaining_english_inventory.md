# Инвентаризация оставшегося английского текста

## Итог

После проверки всех отслеживаемых авторских файлов пропущенных переводов не осталось. Наличие латиницы само по себе не означает английское предложение.

| Категория | Местонахождение | Обоснование |
|---|---|---|
| Намеренно на английском | `docs/architecture/localization_summary.en.md` | Итоговый канал англоязычного сопровождающего |
| Документация сопровождающего | `docs/maintainer_guide.en.md` | Практическое английское руководство, не конкурирующее с русской архитектурой |
| Совместимость | прежние идентификаторы формул, имена модулей и JSON-значения | Замороженные внешние значения |
| Машинная поверхность | исходный код, заголовки, CMake, тесты, имена файлов и команд | Идентификаторы, ABI/API, сообщения, MIME, пути, сериализация и ожидаемые тестовые строки |
| Стороннее | `CDC.pdf` | Неавторский неизменяемый источник |
| Цитата | цитируемые фрагменты и библиографические названия в `docs/research/` | Сохраняют точность источника |
| Исследовательская нотация | `docs/research/`, документы CDC | Формулы, символы и установленные имена объектов |
| Пропущенный перевод | отсутствует | При аудите не найден |

Английские заголовки-заполнители в сохранённых README поверхностей заменены ранее; лаконичные названия программных сущностей внутри обратных кавычек переводить нельзя. Будущая проверка должна рассматривать предложения в контексте, а не запрещать ASCII или латиницу.
