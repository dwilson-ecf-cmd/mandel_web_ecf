# Предложение по очистке репозитория

Это только предложение: текущий этап не выполняет перемещений, удалений или переименований.

| Сейчас | ↓ | Будущее | Условие |
|---|---|---|---|
| прежние корневые приложения и серверы | ↓ | `legacy/applications/`, `legacy/servers/` — выполнено | дальнейший вывод только после карты потребителей |
| прежние корневые исполняемые файлы | ↓ | `legacy/binaries/` — выполнено | сохранены режимы, платформа и контрольные суммы |
| корневые BMP, MP4, `frames/` | ↓ | управляемый набор эталонов или внешнее хранилище | определить обязательные эталоны |
| `runtime/src/scheduler.c` | ↓ | `legacy/runtime/` | подтвердить отсутствие сборочных и внешних зависимостей |
| `server/renderer/` | ↓ | узкий `compat/renderer/` либо удаление | заменить тестовую зависимость адаптера |
| корневой UI и пустые границы `web/` | ↓ | единая структура `web/` | утвердить владельца продукта |
| исторические аудиты среди действующей архитектуры | ↓ | `docs/history/` | сохранить ссылки и добавить указатель перенаправления |
| исследование CDC в собираемом ядре | ↓ | отдельная опциональная цель | подтвердить, что штатная среда не зависит от символов CDC |

## Последовательность

1. Зафиксировать потребителей и контрольные суммы.
2. Добавить проверки отсутствия неявных зависимостей.
3. Выполнять по одному механическому перемещению на изменение.
4. После каждого шага повторять полный нативный набор и замороженные идентичности.
5. Удалять только после отдельного решения сопровождающего.

## Реализация первой части

Перемещение исходных автономных приложений, серверов и трёх двоичных справочных файлов выполнено в `legacy/`. Предложения для совместимого рендерера, раннего планировщика, UI, носителей, исторических документов и CDC остаются будущими и не получают автоматического разрешения.

## Снятие Python-сервера

Предложение для `legacy/servers/server.py` выполнено после отдельного разрешения владельца: компонент имеет статус `RETIRED`, а Git служит архивом. Это решение не распространяется на C++-сервер или другие сохранённые поверхности.

## Завершение очистки исполняемой эпохи

Предложения для исходного C++ HTTP-сервера и трёх иностранных исполняемых файлов выполнены после отдельного разрешения владельца. Git хранит байты и режимы; записи о снятии фиксируют суммы. Исходные автономные рендереры, UI, носители, совместимый рендерер и CDC не затронуты.

## Завершение автономных исходных рендереров

После аудита уникальных знаний предложение для двух исходных рендереров выполнено: статус `RETIRED`, архив — Git. UI, носители, совместимый рендерер, ранний scheduler и CDC остаются без изменений.
