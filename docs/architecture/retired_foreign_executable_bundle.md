## Решение и восстановление

Владелец разрешил удалить комплект из активного дерева: он не входит в CMake, не является переносимым артефактом выпуска, не требуется тестам, UI, совместимому рендереру или современной среде выполнения и не должен служить прототипом будущих клиентов или службы. Сохранение исполняемого режима не добавляло архитектурной ценности и повышало риск случайного запуска иностранного файла.

Git сохраняет точные байты и режимы. Для восстановления использовать `git log --all -- legacy/binaries/<имя>` и `git show <commit>:legacy/binaries/<имя>` в отдельной ветви. Удаление выполняется коммитом `Retire native server and foreign executable bundle`.

Это разрешение само по себе не распространялось на исходные рендереры. Они позднее получили отдельное разрешение после аудита знаний и описаны в `retired_standalone_renderers.md`. UI, носители, совместимый рендерер и CDC по-прежнему не охвачены.
