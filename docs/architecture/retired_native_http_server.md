# Снятие с эксплуатации исходного нативного HTTP-сервера

Статус: `RETIRED`.

## Происхождение и поведение

Исторические пути: `server.cpp`, затем `legacy/servers/server.cpp`. Компонент представлял автономный однопоточный HTTP-сервер C++, слушал `INADDR_ANY` на порту `8080` и выводил пользователю адрес `http://localhost:8080`. Для запроса, содержащего `GET /render`, он вычислял фиксированное изображение Mandelbrot 600 × 400 собственной встроенной математикой и возвращал BMP. Для остальных запросов он читал `index.html` из текущего каталога и возвращал его как HTML.

Сервер не запускал внешний процесс и не строил команду оболочки: вычисление выполнялось внутри процесса. Проверки ошибок сокета, привязки, чтения файлов и частичной передачи отсутствовали; разбор HTTP сводился к поиску подстроки в буфере фиксированного размера. Не были предусмотрены аутентификация, шифрование, ограничение ресурсов, изоляция задания или безопасный жизненный цикл службы.

Двоичный файл `app_server` соответствовал этой эпохе и сохранялся как справочный AArch64 Android/Termux ELF-файл, но не являлся воспроизводимой современной целью. Сервер и `app_server` не задают прототип либо требование совместимости для будущего направления: общие сервисные контракты → локальный настольный клиент → удалённый Android-клиент → защищённая служба управления → изолированные современные рабочие процессы среды выполнения.

## Решение и восстановление

Владелец разрешил снять компонент с эксплуатации. Авторитетные переносимые контракты находятся в `shared/`, модульное выполнение — в `runtime/`; будущие клиенты, служба управления и рабочие процессы требуют отдельных контрактов и не реализуются этим этапом.

Размер перед удалением: `3457` байт. SHA-256: `ff2c3d6464962298dc040ece72ae3a631da55b4ba6a3195b6b4f3a7074e5bbe1`.

Git является архивом. Для поиска и просмотра использовать `git log --all -- legacy/servers/server.cpp` и `git show <commit>:legacy/servers/server.cpp`. Удаление выполняется коммитом `Retire native server and foreign executable bundle` и не разрешает удаление иных компонентов.
