# Владение каталогами

| Каталог | Владелец | Полномочия | Допустимые зависимости |
|---|---|---|---|
| `shared/` | переносимое ядро | контракты, модели, реестр | стандарт C11 |
| `runtime/` | среда выполнения | авторитетные модули и композиция | `shared/`, Threads |
| `server/renderer/` | слой совместимости | наследуемая граница и C++-адаптер | `shared/`, `runtime/` через утверждённые цели |
| `server/computation/` | исследовательский слой | вычислительная подложка CDC | общие контракты; без активации CDC |
| `tests/` | проверка контракта | поведение, идентичности и границы репозитория | авторитетные цели; статическое чтение `legacy/` допустимо |
| `docs/architecture/` | архитектурная документация | русские действующие контракты и аудиты | языковая политика и словарь |
| `legacy/` | хранитель происхождения | инертные приложения, серверы и двоичные данные | не может быть зависимостью продукта или исполняемой целью |
| `web/` и корневой UI | будущий интерфейс / совместимость | интерфейс пока остаётся на прежнем месте | не требуется нативной сборке |
| `frames/` и корневые носители | хранитель результатов | сгенерированные исторические данные | не требуется конфигурации или компиляции |

Перемещение между владельцами требует отдельного архитектурного решения. Нативная сборка не должна собирать, связывать, копировать или запускать содержимое `legacy/`.
