# Идентичность устройства

Устройство — физическая или логическая установка клиента, например Android-приложение или настольный клиент. Запись содержит стабильный идентификатор устройства, идентификатор участника после одобрения, отпечаток открытого ключа, класс платформы, сводку аттестации, состояние зачисления, состояние отзыва и версию ключа. Один участник может иметь несколько устройств. Переустановка Android-приложения создаёт новый ключ и новое устройство; старые метаданные не восстанавливают доверие. Будущая Android-реализация должна использовать Android Keystore и предпочитать аппаратно защищённые ключи, но контракт хранит только платформенно-нейтральную сводку.
