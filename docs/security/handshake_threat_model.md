# Модель угроз рукопожатия

Контракт должен отклонять украденное или повторно использованное приглашение, перебор кода, повтор доказательства устройства или сервиса, MITM-подмену, неправильный сервис, неправильное устройство, изменение транскрипта, эскалацию возможностей, замену роли, истёкшее приглашение, повторное одобрение, подключение отозванного устройства, клон метаданных полномочия, устаревшую версию ключа, downgrade, прерванный обмен, переустановку приложения, ротацию ключа сервера, спам сопряжения, вредоносный QR-код, скомпрометированный rendezvous-сервис и перекос часов. Короткий код является только подсказкой для человека, не криптографическим секретом. Rendezvous-сервис может ретранслировать метаданные, но не одобряет устройства и не выпускает полномочия.
