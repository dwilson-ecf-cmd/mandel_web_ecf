# Жизненный цикл полномочия участника

Успешное сопряжение выпускает логическую запись полномочия, привязанную к участнику, устройству, сервису и версиям ключей. Запись содержит выданные возможности, набор разрешённых Рабочих областей, время выдачи, срок действия, политику переиздания, эпоху отзыва и статус `ACTIVE`, `EXPIRED`, `REVOKED`, `SUPERSEDED` или `SUSPENDED`. Контракт не определяет переносимый bearer-secret: будущая реализация должна требовать доказательство владения ключом устройства при каждом подключении. Метаданные полномочия без закрытого ключа устройства не аутентифицируют клиента.
