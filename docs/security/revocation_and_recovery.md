# Отзыв и восстановление

Оператор может отозвать сеанс, устройство, участника, весь удалённый доступ, сервисную идентичность или все полномочия до заданной эпохи. Отзыв не требует владения потерянным устройством. При потере телефона устройство отзывается, сеансы завершаются, история участника сохраняется, а замена сопрягается как новое устройство. При переустановке приложения старое полномочие не переносится из данных приложения. При потере ключа сервиса или компрометации сервиса требуется ротация ключей, отзыв сеансов и, при необходимости, повторное сопряжение всех устройств. Локальный настольный оператор сохраняет автономный выключатель удалённого доступа.
