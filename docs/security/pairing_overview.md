# Кратко о сопряжении Fractal Studio

Сопряжение превращает неизвестный телефон или другой клиент в признанное устройство участника Fractal Studio. Оператор создаёт короткоживущее приглашение на настольной стороне или сервисе. Клиент показывает себя сервису, обе стороны доказывают владение своими закрытыми ключами, затем человек сравнивает код или фразу, полученную из того же защищённого транскрипта. Только после явного одобрения оператор выбирает роль и ограниченный набор возможностей. Android получает возможности для чтения и редактирования Рабочей области, но не получает администрирование компьютера. После этого обычное подключение требует доказать владение ключом устройства и проверить статус полномочия; повторное человеческое одобрение не требуется, пока полномочие действительно и не отозвано.
