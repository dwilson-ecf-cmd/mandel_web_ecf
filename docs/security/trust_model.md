# Модель доверия сопряжения Fractal Studio

Инвариант: обнаружение находит возможный сервис Fractal Studio, сопряжение устанавливает идентичность, авторизация выдаёт продуктовые возможности; ни один этап не выдаёт прямое управление узлом. Прогрессия доверия фиксирована: `UNKNOWN`, `DISCOVERED`, `INVITATION_PRESENTED`, `KEY_PROOF_VERIFIED`, `HUMAN_CONFIRMATION_REQUIRED`, `APPROVED`, `PARTICIPANT_CREDENTIAL_ISSUED`, `ACTIVE`. Любая ошибка, истечение срока, отказ, несовпадение или отзыв переводит обмен в закрытое состояние без частичных полномочий. Сервис, устройство, участник и сеанс являются разными идентичностями. Долговременные закрытые ключи не передаются; владение ключом доказывается подписью свежего вызова и идентичности транскрипта. Сопряжение выдаёт только возможности Рабочей области и не включает управление ОС.
