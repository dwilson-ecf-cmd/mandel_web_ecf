# Приглашения сопряжения

`PairingInvitation` — ограниченное одноразовое приглашение. Оно содержит идентификатор приглашения, сервис-издатель, версию ключа сервиса, запрошенную роль участника, максимальный профиль возможностей, время создания, срок действия, одноразовое состояние, nonce, данные проверки человеком, статус и детерминированную идентичность. Статусы: `CREATED`, `ADVERTISED`, `CLAIMED`, `APPROVED`, `DENIED`, `EXPIRED`, `CONSUMED`, `REVOKED`. Приглашение истекает, привязано к одному сервису, не содержит закрытого ключа, не выдаёт полномочий само по себе и блокируется после отказа, истечения, отзыва или потребления. Лимиты попыток защищают короткие коды от перебора.
