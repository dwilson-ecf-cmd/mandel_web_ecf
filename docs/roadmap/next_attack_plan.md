# План следующего этапа

Этап подключаемого контракта формулы завершён. Формулы Mandelbrot и Julia
независимо зарегистрированы, а `fractal.compute.scalar.v1` больше не содержит
их математическое поведение. Зафиксированные поля, пиксели и BMP сохранены.

Следующая архитектурная цель сопровождающим пока не утверждена. До отдельного
решения нельзя считать запланированными новые формулы, числовые реализации,
SIMD, GPU, произвольную или интервальную арифметику, выполнение CDC, Android,
JNI, Kotlin, изменения планировщиков либо изменения анализаторов. Будущий план
должен сохранять русскоязычную политику документации, английскую итоговую
отчётность для сопровождающего и явно перечислять допустимые изменения
идентичности.
